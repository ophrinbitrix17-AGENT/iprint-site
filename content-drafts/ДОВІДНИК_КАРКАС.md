# Довідник (FAQ) — каркас для вёрстки

Статус: **каркас**. Тексты ответов готовит владелец отдельно (VLM-проект). Здесь — только структура, под которую агент готовит шаблоны страниц и разметку. Вопросы-примеры — ориентир для вёрстки, не финальный список.

## Как будет устроено (вёрстка)
- Страница-хаб `/dovidnyk/` — оглавление по разделам + поиск по странице.
- Раздел = отдельная страница `/dovidnyk/<розділ>/` с 5–15 вопросами (подробные разделы ИИ цитирует лучше, чем одна гигантская страница).
- Каждый вопрос — заголовок H2/H3 с якорем (`#скільки-коштує-...`), короткий прямой ответ первым абзацем, затем детали.
- Дата обновления на каждой странице, ссылки на услуги/технологии, разметка FAQPage + BreadcrumbList.
- Источник данных — файлы `site/src/content/dovidnyk/*.md` (один файл = один раздел), формат:

```markdown
---
title: "Терміни та тиражі"
updated: 2026-12-01
status: ДОРАБОТАТЬ
---
## Який мінімальний тираж?
Короткий прямий відповідь (1–2 речення).

Деталі…
```
