# Конвейер изображений

Правило владельца: **фото отдаются как есть** — любой размер, формат, имя. Всё остальное делает агент.

## Путь фото
1. Владелец кладёт файлы в `AGENT/assets-inbox/` (или указывает папку в `Контент`), пишет, для какого блока.
2. Агент отбирает кадр, при необходимости кадрирует под блок (карточка, Hero, галерея).
3. `tools/images.mjs` делает «чистую» веб-копию: поворот по EXIF, удаление метаданных (GPS!), длинная сторона ≤ 2400 px, латинское имя файла по правилу ниже.
4. Копия кладётся в `site/src/assets/images/<раздел>/`. Дальше Astro сам нарезает версии под телефон/планшет/компьютер в AVIF/WebP и ставит ленивую загрузку.
5. Агент пишет `alt` на украинском (что на фото, по делу) и заносит фото в реестр `site/src/content/images.json` (файл → блок → alt → источник).

## Имена файлов на сайте (правило владельца 26.11.2026)
У себя на компьютере владелец хранит файлы как удобно. **При загрузке на сайт агент всегда переименовывает:**
- латиница в нижнем регистре, слова через дефис, без пробелов, кириллицы, `_`, служебных слов (`final`, `v1`, `copy`, `draft`, `img123`);
- 2–6 слов по сути кадра, на украинском в транслитерации (паспортная, КМУ 2010: ш→sh, щ→shch, х→kh, ч→ch, ж→zh, ц→ts, г→h, ґ→g, є→ie, ї→i, й→i, ю→iu, я→ia, ь опускается);
- сначала услуга или технология, потом что в кадре: `shovkotrafaretnyi-druk-na-futboltsi.jpg`, `druk-na-kroi-zamovnyka.jpg`;
- без спама ключевыми словами и без названия бренда iPrint в каждом файле; имя совпадает по смыслу с `alt`.
Сборка сама проверяет имена (`site/src/lib/images.ts`): файл с неправильным именем не соберётся.

## Форматы кадров по блокам (ориентиры, агент подгоняет сам)
| Блок | Пропорция | Мин. исходник | Примечание |
|---|---|---|---|
| Hero | 16:9 компьютер / 4:5 телефон (отдельный кроп) | 2400 px по длинной стороне | Главный объект в центре — переживёт оба кропа |
| Карточки технологий | 1:1 | 1600 px | Макро фактуры, нижняя треть — тихая зона под текст |
| Карточки продуктов | 1:1 | 1600 px | Финальные фото владельца — без кропа |
| Комплексные изделия | 3:2 | 2000 px | Выноски — отдельным слоем (SVG), не впечатаны |
| Галерея страниц | любая | 1600 px | |

## Заглушки
Нет фото — ставится нейтральная заглушка (фирменный halftone-растр + подпись «ФОТО — ДОРАБОТАТЬ»). Сейчас нужны: **Hero (главное фото)**, **Комплексні вироби** (карточки — финальные с 26.11.2026).

**Финальные фото карточек (26.11.2026):** квадрат 1600×1600, проверены VLM-моделью владельца — **не кадрировать, не менять пропорции**; допустимо только сжатие (и срез тонкой кромки, если квадрат неровный). Рамка карточек — 1:1.

## Команды
```bash
cd AGENT/tools
node images.mjs "<источник>" "<результат>" --max=2400            # чистые копии
node images.mjs "<источник>" "<результат>" --crop=1200x900       # принудительный кроп с умным центром
```
