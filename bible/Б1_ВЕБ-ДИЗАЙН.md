# Б1. Библия веб-дизайна iPrint (редакция 17.11.2026)

Обязательна к прочтению перед любой визуальной задачей. Основа — исследования `research/R1_тренды_веб-дизайна_2026.md` и `research/R4_конкуренты_и_референсы.md` (там источники и подробности). При конфликте с `docs/05_ЖУРНАЛ_РЕШЕНИЙ.md` побеждает журнал.

## 1. Направление стиля
**Формула:** спокойная база + один экспрессивный акцент (лайм) + фактура (растр) + реальные фото работ.
- 2026 — реакция на «ИИ-одинаковость»: ценится то, что трудно сгенерировать — реальная фактура принта, нитки, растра, крупная собственная типографика. Это главный козырь iPrint.
- Характер: «инженерная» спокойная подача + живое производство. Не корпоративно-сухо, не «креативное агентство».
- Главный визуальный актив — **макросъёмка реальных работ**, а не графика.

## 2. Палитра (система токенов)
| Токен | Роль | Правило |
|---|---|---|
| `--lime-light` `#A6D93C` | лайм на **светлом** фоне (из `лого.svg`) | **Фиксирован.** Только заливка: кнопка (с графитовым текстом), точки, маркеры, полосы. ≈5–10 % площади. **Никогда не текст** на светлом |
| `--lime-dark` `#A5F200` | лайм на **тёмном** фоне (из `лого.svg`, ярче) | **Фиксирован.** На тёмном может быть и заливкой, и текстом/иконкой |
| графит | основной текст, тёмные секции | |
| тёплая светлая база | фон страницы | тёплый off-white, созвучен серому логотипа (#BFBBB2) |
| тёплый серый `#BFBBB2` | цвет логотипа, фоны/разделители | **не текст** на светлом (1,9:1) |
| тёмная олива (~`#4A6A00`) | акцентный текст и ссылки на светлом | ≥ 4,5:1 |
| служебные | ошибка/успех | проверенные на контраст |

- Источник истины по лайму — `Контент/картинки/ЛОГО+ИКОНКИ/лого.svg` (решение 17.11.2026). Брендбук `#BCEE51` устарел, Webflow `#B7E84A` заменён.
- Шкалы оттенков строить в OKLCH от лайма.
- **Главная кнопка (решение 17.11):** на тёмном фоне — лайм `#A5F200` + графитовый текст; на светлом — **графит `#1A1916` + лаймовый текст `#A6D93C`** (лайм на светлом как заливка сливается, ~1,5:1).
- Контраст: обычный текст ≥ 4,5:1, крупный текст/иконки/рамки ≥ 3:1 — в **обеих** темах.

## 3. Тема: светлая / тёмная
- Исследования (NN/g): светлая тема читается лучше, тёмную по умолчанию не делают.
- **База — светлая страница + тёмные графитовые «сцены»** (Hero, Комплексні вироби, подвал) как композиционный приём: на графите лайм и фото «светятся».
- **Утверждено 17.11: вариант C в тёплой гамме, по умолчанию светлая тема для всех** (не системная). Обе темы делаем. Переключатель ☀/☾ в шапке — два состояния, выбор сохраняется, без «вспышки» неправильной темы. Вариант «как в системе» — только если владелец решит иначе.
- В тёмной теме: лайм — `#A5F200`, фото и принты на тёмной ткани смотрятся естественно; проверять, что цвета фото не «плывут» (без фильтров на изображениях).
- **Переключение по времени суток — не делаем** (нет данных в пользу; ОС пользователя уже умеет по расписанию — сайт, следующий за ОС, наследует это бесплатно).
- Полная тёмная тема — бонус, не приоритет MVP; но токены закладываются сразу, чтобы включить её без переделки.
- Токены варианта C — источник для `site/src/styles/themes/2026-11.css` (переносятся из `design/СТИЛИ_iPrint.html`).

## 4. Типографика
- **Manrope** (фиксирован), переменный, кириллица. Крупные жирные заголовки (700–800) с лёгким отрицательным трекингом; основной текст 16–18 px, межстрочный 1,5–1,6.
- Размеры — «резиновые» (clamp): H1 32→72 px, H2 26→48 px.
- Допустимы техничные подписи параметров (тираж, цвета, lpi) — тем же Manrope в капсе/разрядке; моноширинный — только если владелец одобрит.
- Длина строки текста — до ~65 знаков.

## 5. Фирменная графика
- **Точка-мишень** (лаймовая точка в кольце): маркер подзаголовков, активный пункт, индикатор, фокус. Не перегружать.
- **Halftone-растр:** фон секций, маски на фото, «проявление» при появлении секции. Только CSS/SVG (лёгкий), **никогда под основным текстом**.
- Иконки — линейные, единая толщина 2 px, рисует агент (SVG). Без клипарта.

## 6. Композиция и сетка
- Mobile-first. На телефоне — одна колонка, одна сильная картинка на экран.
- Компьютер — выразительнее: асимметрия, «лесенка» карточек, крупная типографика. Приёмы только сеткой, **не сдвигами за поле** (ошибка Webflow-макета).
- Бенто допустимо (одна крупная плитка-«герой»), порядок плиток проектируется сначала для телефона.
- Любое число карточек в блоке — сетка перестраивается сама.
- Ритм секций: телефон ~56 px, планшет ~80 px, компьютер ~112 px.

## 7. Hero
- **Один статичный экран**, без слайдера (NN/g; Notre Dame: ~1 % кликов по карусели).
- Содержит: ясное предложение (кто и для кого), реальное фото работы, главный CTA, видимый без прокрутки, + второстепенное действие.
- На телефоне первый экран не должен быть пустым (ошибка LIUDIAM) — заголовок и кнопка видны сразу.
- Допустимо короткое беззвучное видео процесса (с постером, без автозапуска при reduced-motion).

## 8. Мобильный UX
- Липкая шапка: логотип + кнопка **«Меню» с подписью** (скрытое меню без подписи используют вдвое реже — NN/g) + ☀/☾.
- **Липкая нижняя панель действий** на телефоне: «Розрахувати» + Telegram (большой палец, зона касания внизу).
- Зона касания ≥ 44×44 px для всех кнопок/иконок.
- Карточки продуктов на телефоне — компактные строки (миниатюра + текст), технологии — сетка 2×2.
- Никаких чат-виджетов поверх кнопок, полноэкранных cookie-баннеров, всплывашек выбора языка.

## 9. Контакт и CTA
- Telegram — основной канал (Украина, B2B). Кнопка «Написати в Telegram» со ссылкой с заготовленным текстом.
- Форма «Розрахувати» — короткая (имя, Telegram/телефон, что нужно — чипами, тираж — диапазоны, файл — необязательно, комментарий). Отправка → Telegram-бот.
- CTA — конкретные («Розрахувати вартість», «Надіслати макет»), не «Відправити». Тексты CTA утверждает владелец.

## 10. Доверие без клише
- **Не делаем:** счётчики «10 000+», «лідер ринку», «висока якість» без доказательств, стоковые фото, ряды одинаковых иконок-обещаний (решение владельца + R1).
- **Делаем:** реальные работы крупно с подписью технологии; логотипы клиентов со ссылкой; процесс контроля в фото.

## 11. Движение
- 100–500 мс; обратная связь кнопки ~100 мс; только `transform`/`opacity`.
- Всё в `prefers-reduced-motion` (замена движения на мягкое появление).
- Без параллакса, 3D, перехвата прокрутки, «стекла» поверх фото.

## 12. Фото (см. CLAUDE.md §7 и `tools/ИЗОБРАЖЕНИЯ.md`)
- Подпись к работе: технология / параметры / бренд (если разрешено).
- Текст на фото — только с подложкой/градиентом, проверка контраста.

## 14. Чек-лист дизайнера перед сдачей
- [ ] Лайм нигде не текст на светлом; контраст пар проверен в обеих темах.
- [ ] На 360 px первый экран содержит заголовок и кнопку.
- [ ] Нет слайдеров, стока, счётчиков, клише.
- [ ] Растр не под текстом; фото с подписями и подложками.
- [ ] Все цвета — токены; нет «магических» значений.
