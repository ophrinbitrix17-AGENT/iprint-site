## 1. Стек (проверен ресерчем 17.11.2026)
| Что | Решение | Примечание |
|---|---|---|
| Генератор | **Astro 7.x**, статический вывод | Node 22 LTS+. Компилятор Astro 7 строже к незакрытым тегам |
| Хостинг | **Cloudflare Workers со статическими ассетами** | Не Pages: Cloudflare официально рекомендует новые проекты на Workers. `_redirects`, `_headers`, превью на каждую ветку (Workers Builds) |
| Домен | DNS домена → Cloudflare (смена NS у регистратора) | Требование Workers для своего домена |
| Код и история | Git + приватный GitHub-репозиторий | Каждая правка — коммит, откат одной командой |
| Форма | Отдельный Worker-эндпоинт `POST /api/lead` → Telegram Bot API | Адаптер Astro не нужен |
| Изображения | `astro:assets` (`<Picture>`, AVIF/WebP, авто-srcset) + `tools/images.mjs` для исходников | Исходники в репо ≤ ~2560 px |
| Шрифт | Manrope, самохостинг пакетом `@fontsource-variable/manrope` (браузер грузит только нужные наборы по unicode-range) | предзагрузка кириллического файла в `<head>` |

## 2. Поддержка браузеров (минимум)
- Chrome/Edge/Firefox — последние 2 версии; **Safari/iOS 16.2+**; Android Chrome — последние версии.
- Отсюда правила:
  - **Не использовать нативную вложенность CSS** в исходниках (iOS < 17.2 не поймёт) — или только если сборка её разворачивает (проверено рецензентом).
  - **Не использовать `light-dark()`** (iOS 17.5+). Темы — через атрибут `data-theme` и переменные.
  - Разрешено: container queries, `:has()`, `clamp()`, `color-mix()`, cascade layers, `aspect-ratio`, `gap`, `dvh/svh`.
  - View Transitions — только как необязательное украшение (Firefox без поддержки).

## 3. Архитектура кода
```
site/
  src/styles/themes/<YYYY-MM>.css   ← токены стиля (единственное место цветов/шрифтов/радиусов/отступов)
  src/styles/base.css               ← сброс, типографика, утилиты
  src/components/                   ← Header, MobileMenu, ThemeToggle, Hero, Section, Card, CardGrid, Cta, LeadForm, Footer, StickyBar, Callouts, Placeholder
  src/content/                      ← тексты (главная, услуги, технологии, довідник) — Markdown/JSON
  src/content/images.json           ← реестр фото: файл → блок → alt → источник
  src/layouts/Base.astro            ← <head>: мета, Schema.org, тема без вспышки
  src/pages/                        ← страницы
  public/                           ← robots.txt, favicon, _redirects, _headers
  worker/                           ← обработчик формы
```
- **Один источник правды:** цвет/размер — только токен; текст — только `src/content/`; повторяющийся блок — только компонент.
- **Карточки — данные, не разметка:** блок выводит массив из контента → любое число карточек без правки кода.
- Рестайлинг = новый файл темы `themes/<дата>.css`, переключение одной строкой импорта; старый остаётся для отката.
- **Имена классов и id — без «рекламных» слов** (`adv`, `ad`, `ads`, `banner`, `sponsor`, `promo`, `popup`, `rekl…`, `adbox`…): блокировщики рекламы прячут такие элементы целиком (27.11.2026 EasyList `###adv-title` прятал заголовок у владельца). Сторожит тест в `tests/home.spec.ts`; полная сверка со списками — `tools/adblock-check.mjs`.

## 4. Адаптивность
- Mobile-first CSS: базовые стили — телефон; расширения — `@media (min-width: …)` / container queries.
- Контрольные ширины: **320, 360, 375, 390, 393, 414, 430** (телефоны; 375 — самая массовая в Украине), **768** (планшет), **910, 1024, 1093, 1280, 1366, 1440, 1920** (компьютер; 910 и 1093 — ноутбук 1366 с масштабом Windows 150 % и 125 %).
- **Пороги раскладки (27.11.2026):** телефон < 700 px · планшет 700–899 px · **компьютер ≥ 900 px** (меню в шапке, Hero «текст слева, фото справа», карточки в ряд). Порог был 1100 px — ноутбук 1366×768 с масштабом Windows 125 % (окно ≈ 1093 px) и 150 % (≈ 910 px) получал планшетную версию. В CSS-медиазапросах переменные не работают, поэтому порог — число `900px` во всех компонентах; менять — везде сразу и прогонять `tests/adaptive.spec.ts`. Узкий компьютер 900–1099 px — свои ступени: Hero 58/44 %, «без ризиків» 2×2 до 1000 px, форма заявки в две колонки только с 1100 px, компактнее поля карточек.
- Без горизонтальной прокрутки ни на одной ширине. Учитывать `env(safe-area-inset-*)` (iPhone с «чёлкой»), `100svh` вместо `100vh` для первого экрана.

## 5. Тема (светлая/тёмная)
- По умолчанию — системная (`prefers-color-scheme`); переключатель в шапке на два состояния; выбор в `localStorage` (всегда в `try/catch`); возврат к варианту, совпадающему с ОС, очищает сохранённое значение.
- Маленький inline-скрипт в `<head>` ставит `data-theme` **до отрисовки** (без вспышки). При включении CSP — разрешить его через hash.
- `color-scheme` и `<meta name="theme-color">` для обеих тем.

## 6. Производительность (Core Web Vitals)
| Метрика | Цель (телефон, 75-й перцентиль) |
|---|---|
| LCP | ≤ 2,5 с (цель 1,8 с) |
| INP | ≤ 200 мс |
| CLS | ≤ 0,1 |
| Lighthouse Performance (мобильный) | ≥ 90 |
- Фото первого экрана: `priority` (fetchpriority=high, без lazy); остальные — `loading="lazy"`; у всех заданы размеры (нет скачков).
- JavaScript — минимум: меню, переключатель темы, форма. Без jQuery, без тяжёлых библиотек, без слайдеров.
- Анимации — только `transform`/`opacity`, в `prefers-reduced-motion`.

## 7. Доступность (WCAG 2.2 AA)
- Контраст: текст ≥ 4,5:1, крупный текст и элементы интерфейса ≥ 3:1 — в обеих темах.
- Зона касания ≥ 44×44 px (минимум по стандарту 24, но мы держим 44).
- Видимый фокус (лаймовое/оливковое кольцо), навигация с клавиатуры, `aria-expanded` у меню, `aria-label` у иконок.
- Семантика: `header/nav/main/section/footer`, один `h1`, логичные `h2/h3`, списки — списками, `lang="uk"`.
- Формы: подписи к полям, понятные ошибки, без «только плейсхолдер».

## 8. Форма → Telegram
- Токен бота и ключ Turnstile — **только в секретах Worker**, никогда в коде сайта/репозитории.
- Защита от спама: Cloudflare Turnstile (проверка на сервере) + скрытое поле-ловушка + ограничение частоты.
- Файл макета: ограничение размера (лимиты Bot API уточнить при реализации), иначе — просьба прислать в Telegram.
- Запасной путь при сбое Telegram (e-mail/сообщение «напишіть нам у Telegram»).
- Согласие с политикой конфиденциальности (страница обязательна; действующий закон — 2297-VI).

## 9. Безопасность
- HTTPS + HSTS, заголовки через `_headers`: `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, базовый CSP.
- Никаких секретов в репозитории.

## 9а. Индексация превью
- Сборка по умолчанию = превью: `noindex` в meta и `X-Robots-Tag` в `_headers` (`scripts/postbuild.mjs`). Боевая — только `SITE_ENV=production`. robots.txt на превью не запрещает обход (иначе поисковик не увидит noindex).

## 10. Git и публикация
- Ветка на задачу → превью-ссылка → рецензия и тест → «ок» владельца → слияние в `main` → боевой сайт.
- Сообщения коммитов — по-русски, коротко: что и зачем.
