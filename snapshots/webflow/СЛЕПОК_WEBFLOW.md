## 3. Что технически не так (почему не переносим код 1-в-1)
- **Телефон не проработан** — сознательно: по словам владельца, макет делался только под ПК, до адаптации проект не дошёл. На весь сайт одно правило для мобильных. На экране 375 px шапка не помещается: логотип и «Розрахувати» уходят за край, сетки 4–6 колонок не перестраиваются.
- Фото подключены как фон (background-image) — для Google/ИИ их не существует, нет описаний (alt), не сжимаются под телефон.
- Ссылки-заглушки `#`: меню, карточки, телефон, e-mail, Instagram никуда не ведут (телефон не набирается по нажатию).
- Классы с автоименами (`div-block-7`, `slide-4`, …), дубли стилей, приёмы через сдвиги (`transform`) — отсюда «карточки за полем».
- Нет мета-описания, иконка сайта стандартная Webflow, заголовок вкладки «Iprint.com.ua», нет `lang="uk"`.
- Подключены jQuery и скрипты Webflow (~100 КБ) только ради слайдера.
- Иерархия заголовков: H4 в карточках без H3, `<strong>` внутри H1 для размера.

## 4. Что берём в новую разработку
- **Порядок блоков и тексты** — да (с правками из ревизии).
- **Цветовая логика:** тёмный графит + лаймовый акцент + тёплый серый — это уже по айдентике (Accent Green ≈ лайм, Coal Black). Life Blue из брендбука пока не задействован — предложу варианты на этапе стиля.
- **Шрифт Manrope** — как стартовый кандидат.
- **Числа** (скругления 6 px, кнопки 14×28, ритм 80/120 px) — как отправная точка для файла стиля.
- **Идея «лесенки» карточек** — только на широком экране, сделанная сеткой, а не сдвигами.

## 5. Что не берём
Слайдер (решено: один Hero), код Webflow, фоновые картинки вместо настоящих изображений, заглушки отзывов, выноски, впечатанные в фото (сделаем их отдельным слоем — читаемо на телефоне и понятно ИИ).
