# Папка design — визуальные шаблоны

- **`СТИЛИ_iPrint.html`** — витрина стилей. Открыть: двойной клик (откроется в браузере). Сверху переключатели варианта, темы и экрана (телефон/планшет/компьютер). Работает без интернета.
- `ПАЛИТРА_РЕВИЗИЯ.md` — откуда взяты цвета и почему рекомендован вариант C.
- `img/` — облегчённые копии фото для макетов (делаются `tools/images.mjs`), версии логотипа для светлой/тёмной темы.
- `fonts/` — Manrope (свободная лицензия OFL).

Это эскизы стиля, а не код сайта. После выбора варианта токены переносятся в `site/src/styles/themes/`.
