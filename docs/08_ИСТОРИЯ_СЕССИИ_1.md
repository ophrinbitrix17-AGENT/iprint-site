## 2. Обратная связь владельца — что он поправлял и чему это учит

1. **«Не смешивай всё в кашу».** Агент в одном ответе смешал маркетинг (кому продавать DTF-рулоны, блок цифр, аватар) с вёрсткой. Владелец: маркетинг и продуктовая линейка — **отдельная работа в его VLM-проекте**, здесь только веб-дизайн и вёрстка; ответы — **раздельными блоками**: Маркетинг (совет) / Веб-дизайн / Веб-вёрстка / Администрирование.
2. **Агент ошибся с клиентом DTF-рулонов** («цех с термопрессом»). Владелец поправил: это корпоративные клиенты, спортивные секции, бренды с прессом. Урок: **не делать выводов о клиентах и рынке** — это зона владельца; если очень нужно — спросить, пометив как совет. При этом владелец подчеркнул: «не хочу быть резким, хочу обсуждать на равных» — несогласие нормально, тон спокойный.
3. **Блок цифр «10 000+»** — владелец отклонил как штамп 15-летней давности: «кто это читает, почему должен верить». Факты — в «Про компанію» и Довіднике, и формулирует их он через VLM.
4. **Второй баннер** — не нужен (статистика + его опыт). Один Hero.
5. **Флок** — оставлен «на тест»; владелец объяснил: флок у них — это рисунки шелкотрафаретом, не площадное напыление; при нецелевом трафике уберут.
6. **Цифры старого сайта устарели**: «1–3 дні» → типовые 5–7; «понад 60 прань» → «до 60»; «№1 за термінами» — неактуально; «7 млн малюнків» → больше 10 млн, но владелец считает это бессмысленным для клиента.
7. **Ключевое преимущество** (владелец усилил): шелкотрафарет делает **плавный переход растра в ткань (100 % → 0)**; DTF не умеет (край плёнки, белесый клей, подложка), DTG — тонкий слой, ограничен тканями, дороже на тиражах. Рынок думает наоборот — это козырь. Визуально: принты на тёмной ткани.
8. **Позиционирование «партнёр, а не подрядчик»**, комплексные проекты (PDF + архив, 4–5 видов костюмов, капсулы), ИИ-оценка за 15 минут — для главной (смысл) и будущей страницы «Проєктний запит».
9. **Тёмный фон «грузит», светлый «несерьёзный»** → исследование + витрина → решение: светлая страница + тёмные «сцены». Владелец не понял слово «сцены» — **объяснять одной фразой, без жаргона**.
10. **«Почему иногда открывается тёмным»** — витрина брала тему из Windows. Урок: дефолты должны быть предсказуемыми; объяснять причину простыми словами.
11. **«Где меню?»** — в узкой панели было свёрнуто в «Меню». Урок: показывать скриншотами телефон и компьютер, когда речь о навигации.
12. **Инструкции для владельца — в теле ответа, не отдельным файлом** («так мне неудобно»), простым языком, не супер-подробно. Файл можно сделать дополнительно для агентов.
13. **Владелец хвалил**: системность, витрину стилей с переключателями, адаптацию под устройства, то, что находки (растровый шелкотрафарет как незанятая ниша) агент нашёл сам.
14. **«Не останавливайся, если чего-то нет»** — ищи альтернативу и сообщи (так было со списком топ-20, которого не нашлось сначала).
15. **Карт-бланш**: на подготовке и на MVP владелец сказал «план тебе, не мне — выполняй»; создание — свободно, удаление/замена существующего — спросить. Финальную рецензию (визуал, фото, правки) делает владелец.

## 3. Ключевые находки исследований (подробно — `research/`)
- Тренд 2026 — ответ на «ИИ-одинаковость»: реальные фото/фактура, крупная типографика, halftone как ДНК бренда. Слайдеры, сток, счётчики, «стекло» — устарели. (R1)
- Светлая тема читается лучше (NN/g); тёмную по умолчанию не ставят; переключение по времени суток — не делать. (R1)
- Лайм на светлом как текст — 1,5:1, нельзя; только заливка; для текста — олива `#4A6A00`. (R1)
- Стек: Astro 7, Cloudflare **Workers** (не Pages), для своего домена — NS на Cloudflare; Core Web Vitals без изменений. (R2)
- GEO = нормальное SEO; ИИ-боты не исполняют JS; llms.txt бесполезен; FAQ-сниппеты Google отключены (05.2026), но разметка нужна для сущности; упоминания бренда на других сайтах важнее ссылок; Cloudflare может сам блокировать ИИ-ботов — проверить при запуске. (R3)
- Украинские конкуренты — шаблоны и сток; никто не показывает полноцветную растровую шелкографию как премиум; среди топ-20 мировых никто не продаёт печать на изделиях клиента как услугу. (R4, R5)

## 4. Что построено (состояние на конец сессии)
- `site/` — Astro 7: главная, «Про компанію», «Контакти», «Політика конфіденційності» (черновики), «Дякуємо», «Помилка», 404. Стиль `src/styles/themes/2026-11.css`. Тексты — `src/content/*.json`.
- `site/worker/index.ts` — обработчик заявок → Telegram (тестовый режим до бота).
- Автотесты Playwright: 142 (Chrome, Safari/WebKit, Android, iPhone, планшет); Firefox — в CI (`.github/workflows/tests.yml`), локально Windows его блокирует.
- Git: репозиторий в `AGENT`, ветка `main`; на GitHub ещё не отправлен.
- Не сделано: публикация (ждём аккаунты владельца), подключение бота, аналитика, финальные фото и тексты владельца, проверка на живом iPhone.

## 5. Как работали с рецензентами (проверенный процесс)
1. После работы — 3 рецензента параллельно (вёрстка, дизайн, GEO), каждый читает свой файл `.claude/agents/*.md` и «библию».
2. Сводка блокирующих → исправления одним заходом → полный прогон тестов → **отдельный агент-перепроверщик** подтверждает каждый пункт.
3. Рецензенты реально находили серьёзное: фото не заполняли рамки (обёртка `<picture>`), заявки терялись при спешащих часах клиента, ошибка без JS показывалась как успех, персональные данные в логах, сгенерированное фото как «наша работа».
