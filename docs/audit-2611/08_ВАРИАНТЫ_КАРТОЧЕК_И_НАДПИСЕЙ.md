## Б. Карточки технологий (рамка и сетка; фото — у другого рецензента)

Причина «случайного набора скриншотов»: рамка `--line` `#D9D4CA` к белой карточке 1,48:1, а к фону раздела `#ECE9E2` — 1,22:1, то есть края карточки почти нет; фото идут в край, поэтому разные цвета фото и становятся границей. Плюс 4 в ряд = 281 px против 381 px у услуг.

На телефоне Б1–Б4 отличаются только контуром (строки уже с полем) — см. `*-iphone-*`.
В тёмной теме: контур `#4A4740` (1,68–1,84:1 к карточке/фону), паспарту — цвет карточки `--surface`; чёрные фото на тёмной карточке всё равно сливаются по краю — это вопрос фото, не рамки.

**Рекомендация Б4** (если владелец не хочет более высокий блок — Б2, он один решает «нестильно»).
- `themes/2026-11.css`: `--card-line: #B3AC9F;` (светлая), `--card-line: #4A4740;` (тёмная и `.stage`); `--card-mat: 10px;` `--card-mat-radius: 8px;`.
- `Card.astro`: `.card { border-color: var(--card-line); }`; hover оставить `--line-strong`.
- `CardGrid.astro`, ≥ 1100 px: `.grid--tech .card__media, .grid--products .card__media { margin: var(--card-mat) var(--card-mat) 0; border-radius: var(--card-mat-radius); }`; 700–1099 px — то же для `.grid--tech`.
- `CardGrid.astro`, ≥ 1100 px, только tech: обёртка `.wrap` → `display: grid; grid-template-columns: 1fr 2fr; gap: 20px; align-items: start;`, `.grid--tech { grid-template-columns: repeat(2, 1fr); }`, лесенка `:nth-child(even) translateY(48px)` остаётся. Заголовок не делать «липким» — на мокапе липкий уезжал в середину.
- Замечание: контур карточки < 3:1 допустим — карточку опознаёт текст и белая заливка, контур декоративный. Если нужна строгая 3:1 — `--line-strong` `#857F75` (3,97 / 3,27:1), но это уже заметно тяжелее.

## Мнение арт-директора
Обе жалобы владельца по делу. В «А» лайм должен жить в фирменном знаке, а не лежать на буквах — крупная мишень с графитовым кольцом даёт и бренд, и чистоту. В «Б» проблема не в фото, а в отсутствии общего «паспарту»: одинаковое белое поле и чёткий контур превращают четыре разных кадра в серию, а 2×2 выравнивает их по весу с услугами.
