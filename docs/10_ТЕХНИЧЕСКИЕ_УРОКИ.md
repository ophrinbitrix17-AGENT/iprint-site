# 10. Технические уроки и ловушки (сессия 1)

Для агента: что уже стоило времени. Проверь здесь, прежде чем изобретать заново.

## Среда (Windows 10, Claude desktop app)
- **Оболочка:** Bash (Git Bash) и PowerShell. Длинные команды с несколькими heredoc и кавычками внутри **ломаются** («unexpected EOF») — и могут выполниться частично. Решение: писать Python/Node-скрипт в scratchpad через Write и запускать его одной короткой командой.
- **Node из Bash** не понимает пути вида `/c/Users/...` в аргументах — давай `C:/Users/...`.
- **Firefox (Playwright) на этой машине не запускается** (`spawn UNKNOWN` / `Permission denied`, даже вне песочницы). Не тратить время: Firefox гоняется в CI (`.github/workflows/tests.yml`).
- **Порт 4321 занят старым сервером** → тесты падают «already used». `TaskStop` фонового `wrangler dev` не убивает дочерние процессы. Освобождать так (PowerShell):
  `Get-CimInstance Win32_Process | ? { $_.CommandLine -match 'wrangler' -and $_.Name -eq 'node.exe' } | % { Stop-Process -Id $_.ProcessId -Force }; Get-Process workerd -EA SilentlyContinue | Stop-Process -Force`
- **Playwright `outputDir` (test-results) очищается** при каждом запуске — скриншоты для просмотра пиши в `site/screenshots/` (в .gitignore).
- **Встроенный браузер:**
  - не открывает файлы вне проекта как живые страницы (только снимок `data:` — без localStorage и относительных картинок) → поднимать локальный сервер;
  - `preview_start` по имени требует `.claude/launch.json` в корне сессии (вне AGENT — запрещено) → запускать сервер командой в фоне и открывать `preview_start` с `url`/`navigate`;
  - скриншоты не снимаются, если окно приложения свёрнуто → проверять через `javascript_tool`/`get_page_text` или Playwright-скриптом;
  - вкладки браузера общие с субагентами — не трогай чужие вкладки и не меняй их размер, пока исследователь работает.
- **`astro preview` — один экземпляр на папку сайта:** второй отказывается («Another astro preview server is already running»), а `--force` закрывает чужой сервер другой сессии. Параллельной сессии — копировать `dist` в свой scratchpad и раздавать его простым статическим Node-сервером на своём порту. `dist` общий: сборка в одной сессии меняет то, что видит превью другой.
- **Масштаб Windows = меньшее окно в CSS-пикселях:** 1366 / 1,25 ≈ 1093, 1366 / 1,5 ≈ 910, 1920 / 1,5 = 1280; высота окна ноутбука 768 с панелями браузера ≈ 530 (125 %) / 430 (150 %). В Playwright: `viewport` в CSS-пикселях + `deviceScaleFactor` (27.11: порог компьютера 1100 px давал ноутбуку владельца планшетную версию).
- **npm 11** пропускает install-скрипты пакетов (предупреждение) — sharp, esbuild, workerd работают и так.
- **Git:** репозиторий в `AGENT`; `.gitattributes` (LF); в .gitignore: `node_modules`, `site/dist`, `site/.astro`, `site/.wrangler`, `site/.dev.vars`, `site/test-results`, `site/playwright-report`, `site/screenshots`. Проверяй `git diff --stat` — однажды `.wrangler` попал в коммит.

## Astro / CSS
- **`<Picture>` оборачивает `<img>` в `<picture>`** с `height:auto` → `object-fit` и фокус не работают, фото не заполняет рамку. Правило: в рамке `picture, img { width:100%; height:100% }`, а для Hero — `position:absolute; inset:0` (иначе WebKit при `max-height` считает высоту от пропорции).
- Атрибут `height` у `<img>` перебивает `aspect-ratio` → `.site img { height:auto }`.
- **Scoped-стили Astro не действуют на элементы дочернего компонента** (например, `<Icon class="…">`): нужен `:global(.класс)`.
- **Конфликт имён классов:** форма называлась `.lead` и унаследовала глобальный `.lead` (вводный текст, `max-width:46ch`). Префиксуй классы компонентов (`lead-form__…`).
- `.field label { padding:0 }` сломал `<label class="btn">` — ограничивать селекторы (`.field > label`).
- Специфичность: `.field [aria-invalid]` проигрывал `.field input[type=text]` — повторяй тег в селекторе ошибки.
- Длинные украинские слова в узких карточках (320 px): `overflow-wrap:anywhere; hyphens:auto`; для «Шовкотрафарет» в данных есть `titleDisplay` с мягким переносом `\u00ad` (Safari без словаря рвёт слово без дефиса).
- `body { overflow-x: clip }` маскирует вылезающие элементы — тест на горизонтальную прокрутку их не ловит; тесты проверяют правый край каждого элемента и `scrollWidth` текстов.
- Совместимость iOS 16.2+: без нативной CSS-вложенности и `light-dark()`; `cssTarget` в `astro.config.mjs`.
- Тема: inline-скрипт в `<head>` до отрисовки; `color-scheme: light` в meta (не `light dark` — иначе вспышка у пользователей с тёмной ОС); выбор в localStorage в try/catch.
- Липкая нижняя панель прячется (IntersectionObserver), пока видна кнопка Hero или форма, и при открытом меню (`body.menu-open`).

## Cloudflare Worker и форма
- Конфиг `site/wrangler.jsonc`: статика из `dist/`, `run_worker_first: ["/api/*"]`, `not_found_handling: 404-page`, `ratelimits` (5/мин), `LEAD_MAX_FILE_MB` (= `site.json → lead.maxFileMb`, тест сверяет).
- **Тестовый режим** без `TELEGRAM_BOT_TOKEN` — заявка принимается, в лог только длины полей (без персональных данных).
- Защита от ботов: поле-ловушка `zx_extra` (имя не распознаётся автозаполнением), время заполнения считает **браузер** (`performance.now()`, поле `e`) — не сравнивать часы клиента и сервера (заявки терялись).
- Без JS: успех → `/dyakuyemo/`, ошибка → `/pomylka/` (обе noindex, без canonical).
- Telegram HTML: экранировать каждое поле **до** обрезки длины; имитация в тестах (`tests/mock-telegram.mjs`) проверяет HTML как Telegram и умеет падать (`FAIL_TG` в имени, файл `fail*.pdf`).
- `Origin: null` → 403 (раньше было 500). Ранний отказ по `content-length` → 413.
- Частичный сбой (текст дошёл, файл нет) → клиенту успех с пометкой, менеджерам предупреждение — без дублей.
- В тестах: `--var LEAD_RATE_DISABLED:1`; время «ускоряется» подменой `performance.now` через `addInitScript`.

## Индексация
- Любая сборка без `SITE_ENV=production` — **noindex** (meta + `X-Robots-Tag` в `dist/_headers`, `scripts/postbuild.mjs`). robots.txt не запрещает обход (иначе noindex не увидят).
- Sitemap: `lastmod` из `meta.updated`/`pages.json → updated`; служебные страницы исключены точным сравнением пути.
- JSON-LD собирается из тех же данных, что видимый текст (`knowsAbout` — из карточек), единая сущность `#org`, крошки с `@id`.
- og-image генерируется `node scripts/og-image.mjs` (Playwright, Manrope latin+cyrillic) — **после** генерации пересобрать сайт.

## Изображения
- `tools/images.mjs` — чистые копии (EXIF-поворот, без GPS, латинские имена); Astro сам режет размеры. Фокус кадра Hero — `imageFocus`/`imageFocusDesktop` в `home.json`.
- Лого: `tools/extract-logo.mjs` вырезает из листа CorelDRAW `лого.svg` две версии (светлый/тёмный фон). SVG без width/height — для sharp `density` маленький (иначе «pixel limit»).
