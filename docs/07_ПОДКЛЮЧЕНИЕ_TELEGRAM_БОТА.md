# 07. Подключение Telegram-бота к форме заявки

Форма уже работает в **тестовом режиме**: заявка проверяется и принимается, но никуда не отправляется. Чтобы заявки приходили в Telegram, нужны две вещи: **токен бота** и **ID чата**. Они вводятся в Cloudflare как секреты — в коде и в чате их нет.

## Шаг 1. Создать бота (владелец, 3 минуты)
1. В Telegram открыть **@BotFather** → `/newbot`.
2. Имя: `iPrint заявки`. Адрес: например `iprint_leads_bot` (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AA...`. Сохранить в менеджер паролей. **Никому не пересылать, в чат агенту не вставлять.**

## Шаг 2. Группа для заявок (владелец, 2 минуты)
1. Создать группу «iPrint · заявки з сайту», добавить менеджеров.
2. Добавить в группу бота (по адресу из шага 1).
3. Написать в группе любое сообщение, например «тест».

## Шаг 3. Узнать ID группы (вместе с агентом, на этапе публикации)
Агент даст ссылку вида `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — владелец сам вставляет свой токен и открывает её в браузере; в ответе ищется `"chat":{"id":-100…`. Это и есть ID чата (число со знаком минус).

## Шаг 4. Ввести секреты в Cloudflare (владелец, на этапе публикации)
Cloudflare → Workers & Pages → `iprint-site` → Settings → Variables and Secrets → **Add** → тип **Secret**:
- `TELEGRAM_BOT_TOKEN` = токен из шага 1;
- `TELEGRAM_CHAT_ID` = ID из шага 3.
Сохранить → Deploy. Агент отправит тестовую заявку и проверит, что она пришла.

## Защита от спама (по желанию, рекомендуется)
Cloudflare → Turnstile → Add widget (домен iprint.com.ua) → получить **Site Key** и **Secret Key**:
- `PUBLIC_TURNSTILE_SITEKEY` — переменная сборки (не секрет);
- `TURNSTILE_SECRET` — секрет Worker.
Без них работает базовая защита (скрытое поле-ловушка + проверка времени заполнения).
