# 04. Техническая архитектура

Статус: предложение, ждёт подтверждения владельца.

## 1. Главное решение: уходим с Webflow на собственный код

**Почему не Webflow**
- Агент не может нормально работать внутри визуального редактора Webflow — только «кликать мышкой» за вас. Медленно и ненадёжно.
- Выгрузка кода и подключение своего домена — только на платных тарифах; хостинг Webflow платный ежемесячно.
- Ограничения на разметку для ИИ и на структуру страниц.

**Что вместо: Astro (генератор статических сайтов)**
Простыми словами: агент пишет сайт из «кубиков» (компонентов), а на выходе получается обычный быстрый HTML — то, что лучше всего читают Google и ИИ-боты (им не нужно запускать скрипты, чтобы увидеть текст).
- **Модульность:** шапка, карточка, кнопка, секция — отдельные кубики. Исправили кубик — изменилось на всех страницах.
- **Тексты отдельно от оформления:** тексты страниц, FAQ, услуги лежат в простых текстовых файлах. Правка текста не может сломать вёрстку.
- **Стиль одним файлом:** все цвета, шрифты, размеры, отступы, скругления — в одном файле «стиля». Рестайлинг = новый файл стиля (например `2027-12`), переключается одной строкой, старый остаётся для отката.
- **Скорость:** картинки автоматически сжимаются и нарезаются под телефон/компьютер (фото в архиве весят по 3–5 МБ — на сайт так нельзя).

Webflow используем только как **референс**: снимаем слепок (структура, цвета, тексты), дальше не нужен.

## 2. Где живёт сайт

| Что | Решение | Цена |
|---|---|---|
| Хранилище кода и история версий | Git (локально в `AGENT/site`) + приватный репозиторий GitHub | бесплатно |
| Хостинг | Cloudflare **Workers со статическими ассетами** (поправка 17.11: Cloudflare рекомендует новые проекты на Workers вместо Pages; быстро в Украине, без лимита трафика, HTTPS). Для своего домена DNS переводится на Cloudflare (смена NS у регистратора) | бесплатно |
| «Зеркало» для проверки | Каждая правка сначала публикуется на тестовую ссылку (`черновик.iprint-....pages.dev`), закрытую от индексации | бесплатно |
| Боевой сайт | iprint.com.ua (подключаем DNS) | только домен |
| Форма заявки | Маленькая серверная функция Cloudflare → Telegram-бот и/или Bitrix24 и/или почта | бесплатно |

**Откат:** любая опубликованная версия хранится; вернуть вчерашний сайт — одна команда.

## 3. Структура папки AGENT

```
AGENT/
├── CLAUDE.md                ← регламент агента (читается автоматически)
├── .claude/agents/          ← роли помощников (рецензент)
├── docs/                    ← проектные документы (ревизия, план, решения)
├── snapshots/               ← слепки: Webflow, старый сайт (только чтение)
├── assets-inbox/            ← сюда вы кладёте новые фото/материалы
└── site/                    ← сам сайт (появится на этапе 1)
    ├── src/styles/themes/   ← файлы стиля по датам (2026-12.css …)
    ├── src/components/      ← кубики: Header, Card, Button, Section, Faq…
    ├── src/content/         ← ТЕКСТЫ: главная, услуги, технологии, FAQ
    ├── src/assets/images/   ← фото для сайта (оригиналы, сжимаются автоматически)
    ├── src/pages/           ← страницы (собираются из кубиков и текстов)
    └── public/              ← robots.txt, llms.txt, иконка сайта
```

## 4. Адаптивность
- Вёрстка **mobile-first**: базовый вид — телефон 360–430 px, затем планшет, затем компьютер.
- Компьютерная версия может быть «дизайнерской» (асимметрия, шахматка, крупная типографика), телефонная — чистая колонка, одна картинка на экран, крупные кнопки.
- Обязательные проверки: 360 px, 390 px, 768 px, 1280 px, 1920 px.

## 5. ИИ-видимость (GEO) — что закладывается в код
- Чистая смысловая разметка: один H1 на страницу, логичные H2/H3, списки, таблицы.
- Schema.org (JSON-LD): Organization/LocalBusiness, Service на каждую услугу, FAQPage, BreadcrumbList.
- `sitemap.xml`, `robots.txt` (ИИ-ботов не блокируем; проверить, что Cloudflare не блокирует их сам). `llms.txt` — не приоритет (ресерч 17.11: крупные системы его не используют).
- Подробные правила — `bible/Б3_GEO_SEO.md`; стандарты кода — `bible/Б2_ВЕБ-ВЕРСТКА.md`.
- Факты в тексте, а не в картинках: год, сроки, тиражи, цены «от», город.
- Описания (alt) для всех фото — по-украински, по делу.
- Скорость: цель — Lighthouse 90+ на телефоне.

## 6. Язык
Только украинский (`lang="uk"`). Структура позволит добавить другие языки позже, но сейчас не закладываем.
