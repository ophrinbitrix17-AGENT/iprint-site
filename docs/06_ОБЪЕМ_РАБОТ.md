Минимальные страницы, без которых MVP можно, но нежелательно запускать: «Про компанію» и «Контакти» (+1 сессия, тексты — ваши). Карточки технологий/продуктов в MVP ведут к форме или помечены «скоро».

**Что ускоряет MVP сильнее всего (ваш приоритет №1):**
1. Выбор стиля из шаблонов (после витрины стиля).
2. Аккаунты GitHub + Cloudflare и доступ к DNS домена.
3. Telegram-бот для заявок (инструкция будет).
4. Фото Hero (до этого — заглушка, запуск не блокирует).
5. Логотип в SVG.
