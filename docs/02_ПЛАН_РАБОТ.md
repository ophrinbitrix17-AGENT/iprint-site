## Этап 2. MVP — главная страница + запуск домена
**Статус 17.11.2026:** форма → Telegram (тестовый режим), «Про компанію», «Контакти», «Політика конфіденційності», «Дякуємо», 404, хлебные крошки, Schema.org, og-image, noindex превью — сделано (ветка `etap2/forma`). Осталось: публикация (GitHub, Cloudflare, домен), подключение бота (`07_ПОДКЛЮЧЕНИЕ_TELEGRAM_БОТА.md`), аналитика, финальные фото и тексты владельца, тест на живом iPhone, CI с Firefox.

- Главная по утверждённой текстовке, mobile-first
- Блоки: шапка → Hero (один) → «Без ризиків» → Комплексні вироби (инфографика) → CTA → Технології → Що можна замовити → Результати співпраці (заготовка) → CTA → подвал. (Блок цифр — не делаем, решение 17.11.)
- Форма «Розрахувати» (телефон/мессенджер + опционально файл) → Telegram-бот
- Объём по задачам — см. `06_ОБЪЕМ_РАБОТ.md`
- Минимальная страница «Про компанію і контакти» (для доверия и ИИ — без неё MVP слабее)
- Техническая база видимости: разметка Schema.org (организация, контакты, услуги), карта сайта, robots.txt, llms.txt, мета-теги, превью для соцсетей, политика конфиденциальности
- Аналитика (Google Analytics 4 / Search Console)
- Карточки технологий и услуг пока ведут на якоря/форму или «скоро» — решим

- Постраничные постоянные редиректы (301) со старого домена на новый — сохраняем накопленную «репутацию» в Google

## Этап 4. Довідник / FAQ — главный инструмент ИИ-видимости
- 30–60 вопросов-ответов, сгруппированных по темам: технологии, сроки, тиражи, цены «от», файлы и макеты, ткани, гарантии, оплата, доставка
- Каждый ответ: короткий прямой ответ в первой фразе + детали
- Разметка FAQ, внутренние ссылки на услуги/технологии
- Источник вопросов: реальные вопросы клиентов из переписок менеджеров (нужна ваша выгрузка)

## Этап 5. Страницы услуг (5–6 шт.)
Шаблон одной страницы: что это → для кого → как проходит работа (шаги) → сроки/тираж/цены «от» → галерея → частые вопросы по услуге → CTA.
Сначала делаем шаблон на одной услуге, утверждаем — остальные по нему.

## Этап 6. Страницы технологий (4 шт. + эффекты трафарета)
Тот же принцип: шаблон → одна страница → остальные.

## Этап 7. Кейсы / Результати співпраці
Отдельные мини-истории проектов с клиентами (задача → решение → результат → фото).

## Постоянно (после запуска)
- Правки текстов, фото, цен — по вашей команде в новой сессии
- Рестайлинг раз в год (новый файл стиля, без переделки страниц)
- Проверка видимости в ИИ: раз в квартал спрашиваем ChatGPT/Gemini/Perplexity «где заказать шелкографию для бренда в Одессе/Украине» и фиксируем результат

---

### Почему FAQ после MVP, а не до
Без главной и домена FAQ некуда «прикрепить», а Google и ИИ должны сначала узнать сам сайт. Но технический фундамент для ИИ (разметка, карта сайта, факты о компании) закладывается уже в MVP — переделывать не придётся.
