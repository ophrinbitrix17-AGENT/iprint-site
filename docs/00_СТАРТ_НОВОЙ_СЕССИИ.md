Обновлено: 17.11.2026 (конец сессии 1). Обновляй этот файл в конце каждой сессии.

## 1. Где мы
- **Этап 0 (подготовка)** — закрыт: регламент, «библия», ресерч, рецензенты, стиль утверждён.
- **Этап 1 (главная)** — принят владельцем.
- **Этап 2 (MVP)** — вёрстка готова и слита в `main`: форма → Telegram (тестовый режим), «Про компанію», «Контакти», «Політика конфіденційності» (черновики), «Дякуємо», «Помилка», 404, Schema.org, og-image, CI.
- **Сайт не опубликован.** Владелец делает 4 шага: аккаунт GitHub, аккаунт Cloudflare, доступ к DNS домена (регистратор — вероятно «Укрхост»), Telegram-бот (`docs/07_…`). Плюс фото по ТЗ (`design/ТЗ_ФОТО_HERO_И_КОМПЛЕКС.md`).

## 2. Что дальше (по порядку)
1. **Финальные правки владельца** — он смотрит сайт глазами, загружает фото, правит тексты. Каждую правку: в ветке → тесты → рецензент по профилю → показать.
2. **Публикация:** GitHub (приватный репозиторий `iprint-site`, push из `AGENT`; вход через браузер — Git Credential Manager), Cloudflare Workers (`wrangler.jsonc`; подключить репозиторий, Workers Builds; переменная сборки `SITE_ENV=production` только для боевого), домен: NS → Cloudflare. Проверить живой `robots.txt` и что Cloudflare не блокирует ИИ-ботов (Б3 §2).
3. **Бот:** секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` вводит владелец в панели Cloudflare; агент отправляет тестовую заявку.
4. **Проверка на живом iPhone** владельцем по короткому чек-листу (Б4 §1).
5. Аналитика (GA4/Search Console) — и тогда обновить политику конфиденциальности.
6. Этап 3 — переезд со старого `iprint.od.ua` (301, Search Console); дальше Довідник, страницы услуг и технологий (`docs/02_…`).

## 4. Как запустить и проверить (из `AGENT/site`)
```bash
npm run build                          # сборка (превью = noindex)
npx wrangler dev --port 4321 --ip 127.0.0.1    # сайт + обработчик формы локально → открыть во встроенном браузере
npx playwright test --project=desktop-chrome --project=desktop-safari --project=android --project=iphone --project=tablet
```
Перед тестами порт 4321 должен быть свободен (см. `docs/10_…`). Тесты сами поднимают сайт и имитацию Telegram.
