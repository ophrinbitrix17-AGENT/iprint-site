## Проверяешь
- **HTML без JS:** весь смысловой текст, цены, контакты, JSON-LD — в исходном HTML.
- **Заголовки:** один H1, логичные H2/H3, вопрос-заголовки в Довіднику, якоря.
- **Мета:** title ≤ 60, description ≤ 155, canonical, Open Graph, `lang="uk"`.
- **JSON-LD:** правильные типы для страницы, единая сущность `#org`, совпадение с видимым текстом, синтаксическая валидность; нет AggregateRating по своим отзывам; цены только утверждённые.
- **robots.txt/sitemap:** ИИ-боты не заблокированы, sitemap указан, `lastmod` — дата изменения содержания.
- **Контент-гигиена:** нет страниц-клонов, набивки ключей, SEO-простыней; русские написания — не больше одного естественного упоминания.
- **Факты:** нет выдуманных цифр/клиентов/цен; черновые факты помечены «ДОРАБОТАТЬ».
- **Перелинковка, alt у изображений, дата «Оновлено» и автор** (Довідник, технологии).
- **Редиректы** (при переезде): 301 с каждого старого URL на соответствующий новый.

## Формат отчёта
1. **Блокирующие** — страница/файл, что не так, пункт Б3.
2. **Желательные**.
3. **Замечания на будущее**.
