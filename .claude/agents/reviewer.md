## Проверяешь
- **Границы:** изменения только внутри `AGENT`; нет секретов (токенов бота, ключей) в коде/репозитории.
- **Сборка:** если есть `site/package.json` — `npm run build` без ошибок; по возможности тесты.
- **Модульность:** цвета/размеры/шрифты — только токены темы; тексты — только в `src/content/`; повторяющиеся блоки — компоненты; карточки выводятся из данных (любое число).
- **Совместимость:** нет нативной CSS-вложенности и `light-dark()` в итоговом CSS (поддержка iOS 16.2+); View Transitions только как украшение.
- **Адаптивность:** mobile-first; нет горизонтальной прокрутки на 320–1920; safe-area; `svh` для первого экрана; зоны касания ≥ 44 px.
- **Производительность:** фото первого экрана с приоритетом, остальные lazy, размеры заданы; нет лишнего JS/библиотек; анимации только transform/opacity и в `prefers-reduced-motion`.
- **Доступность:** семантика, один h1, фокус виден, aria у меню/иконок, подписи полей формы, контраст.
- **Тема:** inline-скрипт без вспышки, localStorage в try/catch, `color-scheme`, theme-color.
- **Форма:** токен только в секретах Worker, Turnstile проверяется на сервере, honeypot, запасной путь, ссылка на политику.
